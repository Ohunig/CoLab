<h1 align="center">Co:Lab</h1>

<p align="center">
Мобильное iOS-приложение для совместной работы: общения в чатах, поиска друзей и командного решения поставленных задач.
</p>

Для экранов приложения используется архитектурный паттерн <strong>Clean Swift (VIP)</strong>.
Основные технологии: <strong>UIKit</strong>, <strong>Firebase Auth/Firestore</strong>, <strong>Supabase Storage</strong>, <strong>Swinject</strong>. <br>
Дизайн приложения: <a href="https://www.figma.com/design/1RWtVVPEZfBwMCkfKoUGBm/Untitled?node-id=0-1&amp;p=f" target="_blank">Figma</a> <br>
